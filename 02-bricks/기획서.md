# 벽돌깨기 게임 기획서

## 1. 목표와 범위

- 웹 브라우저에서 실행하는 1인용 벽돌깨기 게임을 만든다.
- 기획서에 따라 프로그램을 만들고, 변경 요청을 반영해 기획서를 갱신한다.
- 결과 파일은 `02-bricks` 폴더에 저장한다. `brick_game.html`, `brick_game.css`, `brick_game.js`를 각각 분리한다.
- 외부 서비스, 외부 라이브러리, 실제 개인정보를 사용하지 않는다.

## 2. 화면과 배치

- 게임 화면은 가로 1024px, 세로 768px을 기준으로 배치한다. 브라우저 창이 이보다 작으면 화면 전체가 보이도록 비율을 유지하며 줄인다.
- 배경은 흰색(`#FFFFFF`), 막대는 검은색(`#000000`)으로 표시한다.
- 벽돌은 **7층, 총 100개**로 배치한다. 위에서부터 각 층은 빨강 15개, 주황 15개, 노랑 14개, 초록 14개, 파랑 14개, 남색 14개, 보라 14개다.
- 각 벽돌은 가로 58px, 세로 28px이며, 가로·세로 간격은 6px이다. 각 층은 화면 가운데에 놓고 위쪽에는 점수 표시 공간을 둔다.
- 막대는 가로 150px, 세로 16px로 하며 화면 아래쪽에 놓는다. 공은 동시에 3개를 사용한다. 각 공은 지름 18px의 흰 야구공으로 그리고, 빨간 실밥 무늬와 검은 윤곽선을 넣는다.
- 공의 이동과 회전 진행 속도는 기존 설정의 1.5배로 한다. 막대의 이동 속도는 유지한다.

## 3. 조작과 진행

1. 화면을 열면 공 3개는 막대 위에 멈춰 있고, 시작 안내 문구를 보여 준다.
2. 스페이스키를 누르면 공 3개가 각각 다른 가로 방향으로 움직이며 게임이 시작된다.
3. 왼쪽·오른쪽 방향키로 막대를 움직인다. 막대는 게임 화면 밖으로 나가지 않는다.
4. 공은 벽, 막대, 벽돌에 닿으면 튕긴다. 막대에서 맞은 위치와 막대의 이동 방향에 따라 공의 진행 방향과 회전 방향이 바뀐다. 회전은 공의 가로 움직임에 점차 약해지는 영향을 준다. 벽돌에 닿으면 해당 벽돌이 사라지고 점수가 10점 오른다.
5. 공이 화면 아래로 떨어지면 그 공만 사라진다. 공 3개를 모두 놓쳤을 때 목숨이 1개 줄고, 남은 목숨이 있으면 공 3개를 막대 위에 다시 놓는다. 스페이스키로 다음 차례를 시작한다.
6. 벽돌 100개를 모두 없애면 승리한다. 목숨 3개를 모두 쓰면 게임이 끝난다.
7. 승리 또는 게임 종료 화면에서 스페이스키를 누르면 점수·목숨·벽돌을 초기화하고 새 게임을 시작한다.

## 4. 화면에 표시할 정보

- 현재 점수와 남은 목숨을 표시한다.
- 시작 대기, 목숨을 잃은 뒤 대기, 승리, 게임 종료 상태에 맞는 짧은 한국어 안내를 표시한다.
- 모든 화면 문구와 코드 주석은 한국어로 작성한다.

## 5. 파일별 역할

- `brick_game.html`: 게임 화면 구조와 CSS·JS 파일 연결
- `brick_game.css`: 화면 크기, 배치, 색상, 글자 모양
- `brick_game.js`: 키 입력, 공 이동, 충돌 처리, 점수·목숨·게임 상태 관리

## 6. 완료 기준

1. `brick_game.html`을 브라우저에서 열면 1024×768 기준의 흰색 게임 화면이 보이고, 작은 창에서는 비율을 유지하며 축소된다.
2. 벽돌 100개가 7층으로 보이며, 위에서부터 빨강·주황·노랑·초록·파랑·남색·보라 색이다. 각 벽돌 크기는 58×28px이다.
3. 검은 막대의 너비가 150px이고 좌우 방향키로 화면 안에서 움직인다.
4. 공 3개는 스페이스키를 누르기 전에는 움직이지 않고, 누른 뒤에 각각 움직인다.
5. 공이 야구공 모양으로 보인다. 벽·막대·벽돌에 부딪히면 알맞게 튕기고, 막대에서 맞은 위치와 이동 방향에 따라 회전과 진행 방향이 달라진다. 맞은 벽돌은 사라지며 점수가 10점씩 오른다.
6. 공 3개를 모두 놓치면 목숨이 1개 줄고, 목숨 3개를 모두 쓰면 게임이 끝난다. 모든 벽돌을 없애면 승리한다.
7. 승리·게임 종료 후 스페이스키로 새 게임을 시작할 수 있다.
8. HTML·CSS·JS가 지정한 세 파일로 분리되어 있고 외부 서비스에 접속하지 않는다.
