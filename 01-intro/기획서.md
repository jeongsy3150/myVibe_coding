# 자기소개 웹페이지 기획서

## 1. 프로젝트 개요

- 프로젝트명: 처음 만난 친구들을 위한 모모의 자기소개 포트폴리오
- 목적: 같은 수업 친구들이 가상 인물 모모의 기본 정보, 관심사, 대학 생활 목표를 쉽게 알아보게 합니다.
- 대상 사용자: 같은 수업을 듣는 대학생
- 제작 범위: 아래로 내려가며 읽는 한 페이지짜리 웹페이지
- 참고 디자인: 사용자가 첨부한 포트폴리오 화면의 매우 큰 검정 제목, 흰 배경, 오른쪽 인물 영역, 주황색 원형 요소와 넓은 여백을 참고합니다. 원본 이미지나 문구는 복사하지 않습니다.

## 2. 가상 인물 설정

- 이름(별명): 모모
- 나이: 25세
- 성별: 남성
- 신분: 대학교 4학년
- 학과 이름·전공: 경영학과
- 성격: 처음에는 조용하지만 친해지면 이야기를 많이 합니다.
- 취미: 농구 경기 보기, 사진 찍기, 카페 탐방
- 관심 분야: 웹 디자인, 영상 편집, 인공지능
- 좋아하는 음식: 돈가스와 떡볶이
- 대학 생활 목표: 다양한 사람을 만나고 팀 프로젝트 경험을 쌓는 것입니다.
- 인사말: “처음이라 조금 어색하지만 편하게 인사해 주세요!”

> 위 정보는 실습을 위한 가상 정보입니다. 실제 이름, 학번, 연락처, 이메일, 사진은 사용하지 않습니다.

## 3. 화면 구성

### 3.1 상단 메뉴

- 왼쪽에 ‘모모의 소개’를 표시합니다.
- 오른쪽에 ‘소개’, ‘좋아하는 것’, ‘목표’로 이동하는 페이지 안의 링크를 둡니다.
- 스마트폰에서는 링크가 잘리지 않도록 줄바꿈하거나 세로로 배치합니다.

### 3.2 첫 화면

- 왼쪽에는 별명 ‘모모’를 매우 큰 검정 글씨로 한눈에 보이게 합니다.
- 별명 아래에는 인사말과 ‘25세 · 경영학과 4학년’을 짧은 문단으로 보여 줍니다.
- 오른쪽에는 사진 대신 CSS로 직접 만든 가상 인물 그림을 세로 직사각형 안에 배치합니다.
- 그림 왼쪽 위에 주황색 원형 ‘더 알아보기’ 링크를 겹쳐 놓고 소개 영역으로 이동하게 합니다.
- 첫 화면 아래쪽에는 다음 영역의 제목이 보이도록 넓은 여백을 둡니다.

### 3.3 소개 영역

- 나이, 학년, 학과 이름·전공, 성격을 각각 이름표와 함께 표시합니다.
- 실제 개인 정보 없이 모모가 어떤 사람인지 설명합니다.

### 3.4 좋아하는 것 영역

- 첨부 화면의 ‘최근 작업’ 영역처럼 큰 제목을 쓰되, 실제 내용은 ‘좋아하는 것’으로 표시합니다.
- 취미 3가지를 간결한 항목으로 나누어 보여 줍니다.
- 관심 분야 3가지와 좋아하는 음식도 분명한 제목 아래 표시합니다.
- 실제로 만든 작품이나 경력을 꾸며 쓰지 않습니다.

### 3.5 목표와 마무리 영역

- 대학 생활 목표와 친구들에게 전하는 한마디를 보여 줍니다.
- 가상 인물이라는 안내 문구를 넣습니다.

## 4. 디자인 방향

- 전체 분위기: 첨부 화면처럼 검정·흰색 대비가 강하고 여백이 넉넉한 개인 포트폴리오
- 주요 색상: 흰색 배경, 거의 검정색 제목과 본문, 주황색 원형 강조 요소
- 글자: 별명 ‘모모’를 첫 화면에서 가장 크게 쓰고, 짧은 설명은 작은 글씨로 아래에 배치
- 배치: 상단 메뉴 → 왼쪽 큰 별명과 오른쪽 그림 → 기본 정보 → 좋아하는 것 → 목표 순서
- 구분 방식: 첫 화면은 카드 테두리 없이 넓은 여백으로 구성하고, 아래 영역은 가는 선과 제목으로 구분
- 화면 대응: 컴퓨터에서는 글과 그림을 좌우로, 스마트폰에서는 위아래로 배치
- 주황색 원형 링크는 글자가 읽히고 키보드로도 선택할 수 있게 만듦
- 움직임: JavaScript 없이 링크 이동과 CSS의 간단한 반응만 사용

## 5. 사용할 기술

- HTML: 제목, 문단, 목록, 페이지 안의 링크와 화면 구조 작성
- CSS: 색상, 글자 크기, 여백, 배치와 화면 크기 대응
- JavaScript: 사용하지 않음
- 외부 서비스와 외부 라이브러리: 실행에 사용하지 않음

## 6. 파일 구성

```text
01-intro/
├─ 기획서.md
├─ index.html
└─ style.css
```

- `index.html`: 자기소개 내용과 화면 구조
- `style.css`: 포트폴리오형 디자인과 화면 크기별 배치
- 첨부 화면의 인물 사진은 사용하지 않고 CSS로 직접 만든 가상 인물 그림을 사용합니다.

## 7. 구현 단계

### 1단계: HTML로 내용 구성

- 상단 메뉴, 첫 화면, 소개, 좋아하는 것, 목표와 마무리 영역을 작성합니다.
- 별명, 학년, 학과 이름·전공, 성격, 취미, 관심 분야, 목표, 인사말을 각각 쉽게 찾을 수 있게 표시합니다.
- 모든 화면 문구를 한국어로 작성합니다.

### 2단계: CSS로 화면 꾸미기

- 매우 큰 검정 별명, 오른쪽 인물 그림, 주황색 원형 링크와 넓은 흰 여백으로 첨부 화면의 분위기를 만듭니다.
- 컴퓨터에서는 여러 열, 스마트폰에서는 한 열로 읽히게 합니다.
- 페이지 안의 링크를 누르거나 키보드로 선택할 때 위치와 초점이 분명하게 보이게 합니다.

### 3단계: 실행 및 확인

- `index.html`을 브라우저에서 열어 내용과 스타일을 확인합니다.
- 상단 메뉴 링크가 해당 영역으로 이동하는지 확인합니다.
- 컴퓨터와 좁은 스마트폰 화면에서 글이 잘리거나 가로 스크롤이 생기는지 확인합니다.

## 9. 제외 범위 및 주의사항

- 첨부 화면의 실제 인물 사진, 문구, 코드나 유료 템플릿 파일을 복사하지 않습니다.
- 실제 작품, 경력, 회원가입, 로그인, 게시판, 데이터 저장 기능은 만들지 않습니다.
- 실제 연락처, 이메일, 학번과 사진을 사용하지 않습니다.
- 기능을 추가하려면 기획서를 먼저 수정한 후 구현합니다.
